# Intelligent Infrastructure Automation Platform

A modern, automated DevOps platform with full authentication, profile management, and infrastructure automation pipelines.

## Project Structure

```
├── frontend/    # React 18, TypeScript, Tailwind CSS, Vite
├── backend/     # Node.js, Express 5, Prisma ORM, PostgreSQL
└── README.md
```

## Quick Start

### 1. Run the Backend
```bash
cd backend
npm install
npx prisma generate
npm run dev
```
The backend server runs on `http://localhost:3000`.

### 2. Run the Frontend
```bash
cd frontend
npm install
npm run dev
```
The frontend dev server runs on `http://localhost:5173`.
